Getting started with Acme Notes

1. Install

Download Acme Notes for your platform and open it. There is no account to create and nothing to configure before you start writing.

2. Pick a folder

Choose any folder on your disk. Every note is a plain text file in that folder, so your editor, backup tool and search all keep working.

3. Turn on sync

Install the app, choose a folder, and turn on sync. Your notes stay as plain text files you can open anywhere. Questions? See pricing or go back home.
